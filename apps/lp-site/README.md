# lp-site

`apps/lp-site` is the Astro consumer app for the shared `@kufu/ui` design foundation.

## Design Foundation

This app consumes shared styles, design tokens, and fonts from `@kufu/ui`.

```css
@import "@kufu/ui/styles.css";
```

Import the stylesheet from `src/styles/globals.css` and keep Astro-local markup and UI composition in `apps/lp-site`.

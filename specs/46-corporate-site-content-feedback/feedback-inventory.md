# FB 項目インベントリ (issue #46)

`.ai-out/FB/ホームページ.xlsx` / `.ai-out/FB/メーカー一覧.xlsx` から抽出した FB 項目の一覧。

## 抽出方法

両ファイルとも、サイトのスクリーンショット画像の上にテキストボックス・直線図形を重ねた指摘形式。
xlsx を zip 展開し、`xl/drawings/drawing1.xml` の各アンカー (EMU 座標) と `xl/media/*.png` の
配置座標を突き合わせて、指摘図形がどの行のどのテキストを覆っているかを特定した。

- 図形テキスト: `xl/drawings/drawing1.xml`
- 差し替え本文 (挨拶文): `xl/sharedStrings.xml` + `xl/worksheets/sheet1.xml` のセル A154-A159
- 座標系: 既定列幅 64px / 既定行高 24px (`sheetFormatPr defaultRowHeight="18"`)

**黄色ハイライト = テキストボックスによる差し替え指摘、赤い直線 = 取り消し線 = 削除指摘。**
取り消し線が削除を意味することはユーザー確認済 (2026-08-10)。

### A-8 差し替え後のご挨拶本文 (xlsx セル A155-A159、記載順)

```text
　有限会社フクウラは創業30年、機械工具・関連機器の販売をはじめ、各種機械加工や小規模工事を通じて、お客様のものづくりを支えてまいりました。
企業理念である**「『創意』と『誠意』で真心奉仕」**を経営の原点とし、お客様にとって最適なご提案と確かな技術・サービスをご提供することを使命としております。
私は二代目として事業を引き継ぎ、創業者が築いてきた信頼と実績を大切に守りながら、新しい発想や柔軟な対応を取り入れ、これからの時代にも必要とされる会社を目指してまいります。
従業員5名という少数精鋭の体制だからこそ、小回りの利く対応力と、お客様との距離の近さを強みとし、一つひとつのご依頼に責任を持って取り組んでおります。
これからも「創意」と「誠意」を胸に、真心を込めたサービスを通じて、お客様に信頼され、地域社会に貢献できる企業であり続けられるよう、社員一同努力を重ねてまいります。
```

`**` は原文ママ (Markdown 強調の意図と思われる)。実装時は強調表現の扱いを決める必要がある。

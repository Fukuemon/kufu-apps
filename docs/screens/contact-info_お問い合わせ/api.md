# contact-info API との対応

[お問い合わせ](index.md) の項目と、画面の型の項目、API の項目の対応。画面を作る人、API を変える人、仕様と実装を照らす人が読む。

このページは静的に書き出すので、API を呼ばない。フォームの送信の契約は、問い合わせフォームの Design Doc にある。

## 値の対応

| 要素名 | 表示する値        | 画面の型の項目                 | API の項目 |
| ------ | ----------------- | ------------------------------ | ---------- |
| 連絡先 | 電話、FAX、メール | コンポーネントに直接書いている | なし       |
| 電話   | 電話の番号        | コンポーネントに直接書いている | なし       |
| メール | メールのアドレス  | コンポーネントに直接書いている | なし       |

連絡先の値を `content/contact.ts` の 1 か所から読むようにする直しは、作り直しの構成の整理で行う。

## 条件の対応

| 条件                        | 判定に使う値                                 |
| --------------------------- | -------------------------------------------- |
| 画面の幅が 768px 未満である | CSS のメディアクエリ `min-width: 48rem` の外 |

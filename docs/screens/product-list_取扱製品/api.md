# product-list API との対応

[取扱製品](index.md) の項目と、画面の型の項目、API の項目の対応。画面を作る人、API を変える人、仕様と実装を照らす人が読む。

このページは静的に書き出すので、API を呼ばない。値は、content collection の取扱製品のカテゴリとメーカーから読む。

## 値の対応

| 要素名           | 表示する値           | 画面の型の項目                            | API の項目 |
| ---------------- | -------------------- | ----------------------------------------- | ---------- |
| カテゴリの索引   | グループ、番号、名前 | content collection の取扱製品のカテゴリ   | なし       |
| カテゴリの見出し | 番号、名前、社数     | カテゴリの `order` と名前、メーカーの件数 | なし       |
| メーカーの一覧   | メーカーの名前       | カテゴリのメーカーの配列                  | なし       |

## 条件の対応

| 条件                               | 判定に使う値                                 |
| ---------------------------------- | -------------------------------------------- |
| 画面の幅が 768px 未満である        | CSS のメディアクエリ `min-width: 48rem` の外 |
| カテゴリの一覧が、画面に入っている | `#products-category-groups` が画面と交わる   |

## 要素の testid

| 番号 | 要素名                 | testid                                |
| ---- | ---------------------- | ------------------------------------- |
| 1    | ヘッダー               | `site-header`                         |
| 2    | ナビゲーション         | `site-nav-menu`                       |
| 3    | メニューを開く         | `site-nav-toggle`                     |
| 4    | ヘッダーのお問い合わせ | `site-nav-contact`                    |
| 7    | 製品について相談する   | `products-link-contact`               |
| 15   | メーカーの一覧         | `products-maker-list-{カテゴリの ID}` |
| 19   | フッター               | `site-footer`                         |
| 20   | フッター               | `site-footer`                         |

フッターの番号は、「初期表示」の状態で 20、「検索の結果が 0 件」の状態で 19 である。

ナビゲーションの 4 つの項目、カテゴリの索引と一覧の入れ物、カテゴリごとの入れ物の testid は、番号のない要素に付けているので、表に載せない。モックには書いている。

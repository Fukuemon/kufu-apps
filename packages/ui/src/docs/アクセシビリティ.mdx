# アクセシビリティ

基準と確認の方法は、DESIGN.md の「アクセシビリティ」の表にある。表は次の項目を持つ。

- 文字のコントラスト
- 文字でないもののコントラスト
- フォーカスの見え方
- ターゲットの大きさ
- キーボードの操作
- 入力の誤りの伝え方
- 動きを減らす設定

## カタログでの確認

コンポーネントの story は、Vitest のブラウザのテストとして動き、a11y のアドオンが見つけた違反でテストが失敗する。
a11y のアドオンは、押せる領域の大きさを確認しない。押せる領域の大きさは、story の play が確認する（`TARGET-SIZE`）。

画面のカタログ（corporate-site の Storybook）の story は、a11y のアドオンのテストに載らない。

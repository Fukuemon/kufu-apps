# 色

画面とコンポーネントは、セマンティックトークンのユーティリティだけを使う（`COLOR-TOKEN`）。
名前と使う場面は、トークンの文書（`packages/ui/design/tokens.md`）の「色」の表にある。値は `src/tokens/semantic.css` が `src/tokens/primitive.css` を参照して決める。

## 暗い面

要素に `.surface-inverse` を付けると、その中のセマンティックトークンが暗い面の値になる。使い方は、トークンの文書の「テーマ」にある。

<div className="sb-unstyled surface-inverse grid gap-2 rounded-8 bg-surface-canvas p-6">
  <p className="text-body text-text">暗い面の本文（text）</p>
  <p className="text-caption text-text-secondary">
    暗い面の補足（text-secondary）
  </p>
  <p className="text-caption text-text-inverse-secondary">
    暗い面のリンクと補足（text-inverse-secondary）
  </p>
</div>

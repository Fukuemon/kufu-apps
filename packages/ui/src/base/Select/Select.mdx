# Select

決まった選択肢から 1 つを選ぶ欄。ブラウザの `select` を使い、標準の矢印を消して、右に矢印の印を置く。選択肢は `option` を `children` に渡す。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 変種、状態、使う場面、内容の制約、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「Select」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `FOCUS-ONE`
  - `TARGET-SIZE`

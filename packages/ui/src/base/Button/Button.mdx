# Button

操作のボタン。`variant` で塗りと問い合わせへの導線を、`size` で汎用の大きさと CTA の 4 つの大きさを選ぶ。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 変種、状態、キーボードの操作: コンポーネントの文書（`packages/ui/design/components.md`）の「Button」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `PRIMARY-ACTION-ONE`
  - `FOCUS-ONE`
  - `TARGET-SIZE`

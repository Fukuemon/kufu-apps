# Textarea

複数行の文字の入力欄。高さは内容に合わせて伸びる。誤りの状態は `aria-invalid` で表す。`FormField` の中では、`id` と関連付けの属性を `FormField` から受ける。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、変種、状態、内容の制約、キーボードの操作、良い例と悪い例、DADS から外れる点: コンポーネントの文書（`packages/ui/design/components.md`）の「TextInput と Textarea」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `STATE-NOT-COLOR-ONLY`
  - `FOCUS-ONE`
  - `TARGET-SIZE`

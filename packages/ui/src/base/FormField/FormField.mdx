# FormField

入力欄に、見出し、補足の文、誤りの文、必須と任意の印を添える枠。欄（`TextInput`、`Select`、`Textarea`）は `children` に渡す。

## 規則

規則の本文は、デザインシステムの文書の次のセクションにある。

- 使う場面、使わない場面、変種、状態、内容の制約、良い例と悪い例: コンポーネントの文書（`packages/ui/design/components.md`）の「FormField」
- 誤りの文の読み上げ: DESIGN.md の「アクセシビリティ」の「入力の誤りの伝え方」
- 当たる原則: DESIGN.md の「画面を作るときの原則」の次の ID
  - `STATE-NOT-COLOR-ONLY`
  - `SPACING-SCALE`

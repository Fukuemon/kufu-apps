# Kufu のデザインシステムのコンポーネントとパターン

この文書は、[Kufu のデザインシステム](../DESIGN.md)の一部である。コンポーネントとパターンの使い方の規則を持つ。props と振る舞いは、コードとカタログを参照先にする。

## コンポーネント

コンポーネントは `packages/ui/src/components/` に置き、ネイティブの HTML の要素と `clsx` で書く（[ADR-0028](../../../docs/adr/0028-ui-components-native-elements.md)）。  
見た目は `variant`、`size`、`tone`、`layout` の props で変え、コンポーネントは `className` を受け取らない。今の props で表せない見た目が要るときは、コンポーネントに変種を足す。置く位置と余白は、呼び出す側が包む要素で決める。  
Base と Case への分け方と名前の改め方は、カタログを組むタスク（#82）で行う。それまでは、今の名前と置き場のまま書く。

### Button

- 使う場面: 画面の中の操作。問い合わせのフォームの送信
- 使わない場面と、代わりに使うもの: ページを移るときは `LinkButton` を使う
- 変種
  - `variant`: `default`（塗り。hover で面を薄くする）、`cta`（問い合わせへの導線の塗り。hover で面を変えない）
  - `size`: `default`（高さ 48px、角丸 8px）、`cta-sm`（最小の高さ 40px）、`cta-md`（48px）、`cta-lg`（52px）、`cta-hero`（54px）。`cta-` の 4 つは角丸 4px で、`cta-md` を除き hover で全体を薄くする
  - 消した変種: `variant` の `secondary`、`outline`、`ghost`、`destructive`、`link` と、`size` の `xs`、`sm`、`lg`、`icon`、`icon-xs`、`icon-sm`、`icon-lg`。corporate-site が使っていなかった
- 状態: デフォルト、hover、押下、フォーカス、無効
  - 無効のときに押せない理由の示し方: 未定（#78 で決める）
- 内容の制約: ラベルは動詞で終える。1 行に収める
- キーボード: Tab でフォーカスし、Enter と Space で押す

### LinkButton

- 使う場面: ボタンの見た目で、別のページへ移るリンク
- 使わない場面と、代わりに使うもの: 画面の中の操作は `Button` を使う
- 変種: `variant` と `size` は `Button` と同じ
- 状態: デフォルト、hover、押下、フォーカス、無効。無効のときは `aria-disabled` を付け、タブの順から外す
- 内容の制約: 移る先が分かるラベルにする
- キーボード: Tab でフォーカスし、Enter で移る

### Badge と Tag

`Tag` は `Badge` を包み、見た目は同じである。2 つは #82 で `Tag` にまとめる。

- 使う場面: 事業の分類、入力の項目の必須と任意の印
- 使わない場面と、代わりに使うもの: 押せるものには使わない。押せるものは `Button` か `LinkButton` を使う
- 変種
  - `size`: `default`（高さ 30px）、`sm`（入力の項目の見出しの横に置く小さな印）
  - `tone`: `default`（主の色の塗り）、`required`（必須の印。主の色を薄くした面と主の色の文字）、`optional`（任意の印。補足の色を薄くした面と補足の色の文字）。`required` と `optional` は等幅の書体で出す
  - 消した変種: `variant` の `secondary`、`destructive`、`outline`、`ghost`、`link`。corporate-site が使っていなかった
- 状態: デフォルト
- 内容の制約: 1 行に収まる短い語にする。印の文字は色だけに頼らず、「必須」「任意」のように語で書く

### DefinitionRow

- 使う場面: 会社概要のような、見出しと値の組の並び
- 使わない場面と、代わりに使うもの: 列を比べる表は `table` を使う
- 変種: `layout` の `default`（見出しの列 12rem）、`compact`（見出しの列 6.5rem、等幅の小さな見出し）
- 状態: デフォルト
- 内容の制約: `dl` の中に置く

### Separator

- 使う場面: 内容のまとまりの区切り
- 変種: `orientation` の `horizontal`、`vertical`
- 状態: デフォルト
- 内容の制約: 飾りの線で、色は `divider` である。入力欄の枠には使わない

### FormField と Label

`Label` は #82 で `FormField` にまとめる。

- 使う場面: 入力欄に、見出し、補足の文、誤りの文を添えるとき
- 変種: なし
- 状態: デフォルト、エラー（誤りの文を `role="alert"` で出す）
  - エラーのときに色のほかに示すもの: 誤りの文。枠の太さは #78 で決める
- 内容の制約: 見出しは `htmlFor` で欄と結び付ける

### Input と Textarea

- 使う場面: 1 行の文字の入力（`Input`）、複数行の文字の入力（`Textarea`）
- 変種: なし
- 状態: デフォルト、フォーカス、無効、エラー（`aria-invalid`）
- 内容の制約: 見出しは `FormField` で付ける。`placeholder` を見出しの代わりにしない
- キーボード: Tab でフォーカスする

### Select

- 使う場面: 決まった選択肢から 1 つを選ぶとき
- 変種: なし
- 状態: デフォルト、フォーカス、無効、エラー（`aria-invalid`）。値が空の選択肢を選んでいる間は、文字を補足の色で出す
- 内容の制約: ブラウザの `select` を使い、選択肢は `option` で渡す。幅は親の幅に広がるので、呼び出す側が包む要素で幅を決める
- キーボード: Tab でフォーカスし、文字の入力か矢印のキーで選ぶ。選択肢の一覧の開き方と見た目は、ブラウザと OS ごとに違う
